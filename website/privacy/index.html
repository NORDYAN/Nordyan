2. Vilka uppgifter vi behandlar

När du använder NORDYAN kan vi behandla uppgifter som du själv lämnar eller som genereras genom din användning av tjänsten.

Konto- och profiluppgifter kan bland annat omfatta:

  • e-postadress
  • användar-ID
  • ålder eller födelseår
  • kön
  • längd och vikt

Hälso- och livsstilsuppgifter kan bland annat omfatta:

  • kroppsfett och kroppsmått
  • fysisk aktivitet och träningsvanor
  • steg och aktivitetsdata när sådana funktioner används
  • puls och andra hälsomätvärden när sådana funktioner används
  • alkohol- och livsstilsvanor
  • uppgifter från onboarding och återkommande check-ins
  • information som du själv lämnar till NORDYAN Coach

3. Varför vi behandlar uppgifterna

Vi behandlar uppgifterna för att:

  • skapa och administrera NORDYAN-kontot
  • visa hälsodata och utveckling
  • beräkna relevanta mått och jämförelser
  • ge personliga insikter
  • tillhandahålla NORDYAN Coach
  • genomföra onboarding och återkommande check-ins
  • upprätthålla säkerhet och teknisk drift
  • ge support
  • uppfylla rättsliga skyldigheter

NORDYAN är ett verktyg för information, hälsomedvetenhet och livsstilsstöd och ersätter inte professionell medicinsk bedömning, diagnos eller behandling.

4. Rättslig grund och samtycke

Viss behandling är nödvändig för att skapa och tillhandahålla NORDYAN-kontot och tjänsten, till exempel för att autentisera dig och administrera ditt konto.

Hälso- och livsstilsuppgifter kan utgöra särskilda kategorier av personuppgifter. NORDYAN inhämtar därför ett uttryckligt samtycke innan vi samlar in och behandlar de hälso- och livsstilsuppgifter som du själv väljer att lämna.

Samtycket är frivilligt och kan återkallas. Behandling som bygger på samtycke hanteras därefter i enlighet med tillämplig dataskyddslagstiftning. Återkallelse av samtycke är inte detsamma som att radera kontot.

5. NORDYAN Coach och AI

NORDYAN Coach använder AI för att skapa förklaringar och personligt anpassade insikter. När du använder Coach kan relevant information skickas till OpenAI via OpenAI API.

NORDYAN begränsar den information som överförs till det som behövs för funktionen. Enligt OpenAIs policy för API-data används API-data som utgångspunkt inte för att träna OpenAIs modeller, såvida kunden inte uttryckligen har valt det. Se OpenAIs API data usage policies.

6. Lagring och leverantörer

NORDYAN använder externa infrastruktur- och tjänsteleverantörer för att tillhandahålla tjänsten, bland annat:

  • Supabase — autentisering, databas och backend
  • OpenAI — AI-funktionalitet
  • Fly.io — hosting av backendtjänster
  • e-post- och hostingleverantörer — systemmejl och kommunikation

Supabase-projektet som NORDYAN använder är konfigurerat i en EU-region. Det innebär inte att all behandling sker uteslutande inom EU/EES. Vissa leverantörer eller underleverantörer kan behandla information utanför EES. Där så krävs används tillämpliga skyddsåtgärder för internationella överföringar.

7. Hur länge uppgifter sparas

Personuppgifter sparas endast så länge det är nödvändigt för de ändamål som beskrivs i denna policy, eller när lagring krävs enligt lag.

När ett konto raderas raderar NORDYAN kontot och tillhörande användardata från sina aktiva system i enlighet med kontoraderingsprocessen, med förbehåll för eventuell begränsad lagring som krävs enligt lag eller som följer av oundvikliga tekniska backup- och säkerhetsprocesser.

8. Kontoradering

Du kan radera ditt konto i appen via: Profil → Integritet och data → Radera konto.

Kontoradering är oåterkallelig.

9. Dina rättigheter

Enligt tillämplig dataskyddslagstiftning kan du ha rätt till:

  • information om behandlingen
  • tillgång till dina personuppgifter
  • rättelse
  • radering
  • begränsning av behandlingen
  • invändning mot behandlingen
  • dataportabilitet där det är tillämpligt
  • att återkalla samtycke
  • att lämna klagomål till tillsynsmyndighet

Highjump Event AS är etablerat i Norge. Relevant norsk tillsynsmyndighet är Datatilsynet, datatilsynet.no.

Användare i Sverige kan också vända sig till Integritetsskyddsmyndigheten (IMY), imy.se.

10. Säkerhet

NORDYAN vidtar tekniska och organisatoriska åtgärder för att skydda personuppgifter, bland annat:

  • autentisering av användare
  • åtkomstkontroller
  • krypterad kommunikation
  • begränsad åtkomst till backend och administration

11. Automatiserad behandling

NORDYAN kan använda automatiserad behandling för att skapa analyser, jämförelser och rekommendationer.

NORDYAN Coach är avsedd för information och vägledning och används inte för att fatta beslut som har rättsverkningar eller liknande betydande verkningar för dig.

12. Ändringar av policyn

Denna policy kan uppdateras när NORDYAN utvecklas. Väsentliga ändringar kommuniceras på ett lämpligt sätt, till exempel i appen eller via den e-postadress som är kopplad till kontot.
